# BenchLedger

BenchLedger is a private maker inventory and project workspace. Its core tasks are keeping an accurate workshop inventory and planning and progressing a build. Projects and inventory are peer destinations.

A maker needs to distinguish what is owned, what is confirmed usable, what a project requires and what genuinely needs sourcing. Exact identity, compatibility, uncertainty and provenance remain available when a decision needs them. Recorded, ordered or delivered items must never be presented as physically counted or confirmed ready.

The web app supports requirements, revisions, build planning, files, stock observations and sourcing proposals. Optional assembly and PCB tools support detailed work. Shopping is a proposal, never purchase authority. Physical checks remain explicit.

The intended experience is professional, intuitive and easy to understand. Use simplified technical English, clear actions and progressive disclosure. Avoid sales copy, decorative dashboards and gamification. The user has delegated framework and visual design decisions for the current overhaul.

The existing platform is React and Vite. Preserve accessible keyboard and touch use, responsive layouts, light/dark/system appearance, drafts, authentication and optimistic concurrency. UI changes share existing application behaviour with other surfaces. Native mobile development is outside this overhaul.

This public repository uses synthetic fixtures only. Private inventory, hosts, credentials and runtime data stay outside source control.
