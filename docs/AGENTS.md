# Documentation contributor scope

The root AGENTS.md applies. The runtime user guide formerly at this path is
preserved in [agent-quickstart.md](agent-quickstart.md); the detailed MCP guide
is [../apps/mcp/QUICKSTART.md](../apps/mcp/QUICKSTART.md).

Read the document being changed and the authoritative implementation/contract
for the claim. Distinguish implemented, tested, deployed and planned behaviour;
never promote a roadmap promise or green unit test into deployment evidence.
Preserve approval boundaries, stock/evidence meanings, lifecycle distinctions,
privacy and API/UI/MCP parity. Use synthetic examples only.

Update only affected sections and cross-references. Keep operator procedures
and detailed examples in ordinary Markdown references, not auto-loaded
AGENTS.md files. Validate links, commands and consistency with current schemas;
report checks not run. Runtime guides describe supported operations, not
permission to perform every operation when only documentation was requested.
