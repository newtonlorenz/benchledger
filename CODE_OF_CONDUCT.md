# Code of Conduct

## Our standard

BenchLedger should be a welcoming place for beginners, experienced makers, and
professional engineers alike. Be respectful, specific, patient, and generous
with context. Critique ideas and evidence, not people.

Examples of expected behavior include:

- using inclusive, plain language;
- respecting different experience levels and access needs;
- giving actionable technical feedback;
- acknowledging uncertainty and correcting mistakes openly;
- protecting another person's private data and safety.

Harassment, discriminatory language, threats, sexualized attention, deliberate
intimidation, doxxing, and sustained bad-faith disruption are not acceptable.

## Scope and enforcement

This standard applies in project spaces and when representing the project in
public. Report conduct concerns privately to the repository maintainers using a
non-public repository contact channel. Maintainers will review reports promptly,
protect confidentiality as far as practical, and may edit or remove content,
warn participants, temporarily restrict participation, or permanently ban
someone when warranted.

Security vulnerabilities belong in the private process described in
[SECURITY.md](SECURITY.md), not in conduct reports or public issues.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.
