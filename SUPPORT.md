# Support

BenchLedger is pre-release community software with no guaranteed response time.

- **Bug or feature idea:** use the matching issue form after searching existing
  issues. Use synthetic examples and the smallest useful reproduction.
- **Setup question:** open a discussion when the public repository enables them,
  or an issue only when the documentation appears incorrect.
- **Security concern:** follow [SECURITY.md](SECURITY.md); never post sensitive
  details publicly.
- **Private inventory or project data:** do not upload it. Replace names, IDs,
  URLs, prices, files, and credentials with synthetic equivalents.

For self-hosting, begin with [docs/deployment.md](docs/deployment.md). For agent
integration, use [docs/AGENTS.md](docs/AGENTS.md).
